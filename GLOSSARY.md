# Glossary

The words Gray Horizon uses for its own things, and the one translation each
language uses for them **everywhere**: a term translated one way in Company
management is translated the same way in Help, in a notification and in a
refusal. The English column is the game's vocabulary as the in-game glossary
(Help › Glossary) defines it; read the meaning before translating.

Serbian Cyrillic is written from the Serbian Latin column automatically, so
it has no column of its own. A change to a Serbian term is made in Latin.

Status: **draft, machine-assisted, awaiting native review** (November 2026).
A reviewer who changes a term here changes it in the catalogues too, in the
same change (see the end of this file).

## Changing a term

Open a pull request that changes the row here, with the reason. A reviewer
of that language approves it; the maintainer then updates every sentence that
used the old term in one change. Terms are never changed one sentence at a
time.
